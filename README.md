# Portfólio

Portfólio pessoal estático preparado para publicação no GitHub Pages.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub chamado `SEU-USUARIO.github.io`.
2. Conecte este projeto ao repositório remoto.
3. Envie os arquivos com `git push`.
4. Acesse `https://SEU-USUARIO.github.io`.

Se preferir publicar em um repositório com outro nome, ative o GitHub Pages em
`Settings > Pages` e escolha a branch `main`.
