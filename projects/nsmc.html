NSMC Korean Movie Reviews — Data Quality & Exploratory Analysis

Exploratory and data-quality analysis of 200,000 Korean movie reviews from the NSMC sentiment dataset.

Overview

This project examines Korean movie review text data from the NSMC sentiment dataset with a focus on data quality, exploratory analysis and language-aware feature creation.

Key Findings

  • The dataset contains empty texts, duplicate rows and duplicated texts with both consistent and conflicting labels.
  • Review lengths are short overall, with a median of 27 characters.
  • Simple language-aware features such as eojeol count and expressive markers can support later NLP analysis.
  • Manual qualitative annotation can help surface pragmatic categories, but larger samples are needed.

Limitations

  • No additional statistical results should be inferred beyond the analysis documented here.
  • The manual annotation sample is small and exploratory.
  • Future modeling work would require careful handling of duplicates and conflicting labels.
